# 系统接口

## 查询配置热加载状态

`GET /internal/system/config-reload/status`

该接口为内网运维路由，不允许公网访问；请求需要运维令牌和 HMAC 签名，用于查看当前配置热加载监听和最近一次重载结果。

### 请求头

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| X-Ops-Token | string | 是 |  | 运维接口令牌，需匹配 `ops.config_reload_token` |
| X-Ops-Timestamp | string | 是 |  | Unix 秒时间戳，参与运维 HMAC 签名 |
| X-Ops-Nonce | string | 是 |  | 每次请求生成的 16 字节随机数，使用 32 位小写十六进制编码 |
| X-Ops-Body-SHA256 | string | 是 |  | 请求体 SHA256 十六进制摘要，空 body 按空字节计算 |
| X-Ops-Signature | string | 是 |  | 使用 `ops.config_reload_token` 对 `method\nrequestURI\ntimestamp\nnonce\nbodySHA256` 计算 HMAC-SHA256 |

### 安全字段

| 项目 | 字段 |
|------|------|
| 请求签名字段 | 不参与签名 |
| 请求加密字段 | 不参与加密 |
| 响应签名字段 | 不参与签名 |
| 响应加密字段 | 不参与加密 |

### 访问边界

- `/internal/` 只注册到 `internal_server` 独立监听器，公网监听器没有这些路由。
- 只放行本机或私有地址来源；逐行检查全部 `X-Forwarded-For`、`X-Real-IP` 及其逗号分隔值，任一公网来源都在写入 nonce 前拒绝。
- HMAC 时间窗口为 5 分钟，`X-Ops-Nonce` 通过 Redis `SET NX` 在完整剩余有效期内去重；Redis 不可用时返回 HTTP 503，不降级放行。
- 生产跨主机监听必须绑定明确私网 IP 并配置服务端 mTLS；仅回环监听允许使用 HTTP。
- `ops.config_reload_allowed_ips` 仅用于在内网来源上进一步收窄，留空表示使用默认内网边界。

## 查询运行态配置项

`GET /internal/system/config-reload/items`

该接口为内网运维路由，不允许公网访问；请求需要运维令牌和 HMAC 签名，用于查看 API 进程当前已生效的配置项、脱敏 YAML 快照和运行期外部配置视图。

### 请求头

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| X-Ops-Token | string | 是 |  | 运维接口令牌，需匹配 `ops.config_reload_token` |
| X-Ops-Timestamp | string | 是 |  | Unix 秒时间戳，参与运维 HMAC 签名 |
| X-Ops-Nonce | string | 是 |  | 每次请求生成的 16 字节随机数，使用 32 位小写十六进制编码 |
| X-Ops-Body-SHA256 | string | 是 |  | 请求体 SHA256 十六进制摘要，空 body 按空字节计算 |
| X-Ops-Signature | string | 是 |  | 使用 `ops.config_reload_token` 对 `method\nrequestURI\ntimestamp\nnonce\nbodySHA256` 计算 HMAC-SHA256 |

### 查询参数

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| keyword | string | 否 |  | 配置路径、类型或已脱敏展示值关键字，最大 128 字符 |
| sensitiveOnly | bool | 否 | false | 是否只返回敏感配置项 |
| page | int | 否 | 1 | 页码，从 1 开始 |
| pageSize | int | 否 | 20 | 每页条数，最大 100 |

### 安全字段

| 项目 | 字段 |
|------|------|
| 请求签名字段 | 不参与签名 |
| 请求加密字段 | 不参与加密 |
| 响应签名字段 | 不参与签名 |
| 响应加密字段 | 不参与加密 |

访问边界同“查询配置热加载状态”。敏感字段和地址类配置只返回脱敏展示值，接口不会暴露密钥、令牌、密码或连接地址明文。

### data 字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| keyword | string | 否 |  | 当前查询关键字 |
| sensitiveOnly | bool | 是 | false | 是否只返回敏感项 |
| page | int | 是 | 1 | 当前页码 |
| pageSize | int | 是 | 20 | 当前页大小 |
| total | int | 是 | 0 | 当前筛选命中总数 |
| totalItems | int | 是 | 0 | 当前运行态快照配置项总数 |
| sensitiveTotal | int | 是 | 0 | 当前运行态快照敏感配置项总数 |
| sections | array | 是 | [] | 顶层配置段统计 |
| source | object | 是 |  | 当前运行态快照来源和热加载状态 |

| items | array | 是 | [] | 当前页脱敏配置项 |

## 手动触发配置热加载

`POST /internal/system/config-reload/run`

该接口为内网运维路由，不允许公网访问；请求需要运维令牌和 HMAC 签名，会立即重新读取 `-f` 绑定的主配置文件。完整公网 `RestConf`、`internal_server`、AppID/AppKey、JWT secret/有效期/issuer、Security、Collector、数据库和 Redis 等启动期配置变化不会在线替换当前运行值，只会在状态中标记 `restartRequired=true` 并等待统一重启。

### 请求头

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| X-Ops-Token | string | 是 |  | 运维接口令牌，需匹配 `ops.config_reload_token` |
| X-Ops-Timestamp | string | 是 |  | Unix 秒时间戳，参与运维 HMAC 签名 |
| X-Ops-Nonce | string | 是 |  | 每次请求生成的 16 字节随机数，使用 32 位小写十六进制编码 |
| X-Ops-Body-SHA256 | string | 是 |  | 请求体 SHA256 十六进制摘要，空 body 按空字节计算 |
| X-Ops-Signature | string | 是 |  | 使用 `ops.config_reload_token` 对 `method\nrequestURI\ntimestamp\nnonce\nbodySHA256` 计算 HMAC-SHA256 |

### 安全字段

| 项目 | 字段 |
|------|------|
| 请求签名字段 | 不参与签名 |
| 请求加密字段 | 不参与加密 |
| 响应签名字段 | 不参与签名 |
| 响应加密字段 | 不参与加密 |

访问边界同“查询配置热加载状态”。

### 响应说明

响应结构与“查询配置热加载状态”一致。配置文件解析失败时返回业务失败，错误详情进入服务日志。自动 watcher 启动时若处于配置文件原子替换或短暂不可读窗口，会保持运行并按 `hot_reload.check_interval_seconds` 重试；文件恢复后重新校验并加载，不需要重启进程恢复监听。

## 读取 API 文档站根级资源

`GET /internal/docs/:file`

该接口为内网文档资源路由，只允许 Admin 管理后台通过内网代理读取 API 文档站根级 Markdown 资源，例如 `文档首页.md` 和 `_sidebar.md`。管理员文档授权由 Admin 统一维护：入口使用正常路由权限，正文使用 `admin_doc_permission.site=api + path` 精确权限；API 服务不复制角色权限表。API 服务不提供公网文档站；当前只放行 `docs/site/文档首页.md`、`docs/site/_sidebar.md`、`docs/site/接口文档/**/*.md` 和 `docs/site/角色文档/**/*.md`，不会输出 `route_security_manifest.json` 等非 Markdown 机器资产。

### 安全字段

| 项目 | 字段 |
|------|------|

| 请求加密字段 | 不参与加密 |

| 响应加密字段 | 不参与加密 |

### 访问边界

访问边界同“查询配置热加载状态”。调用方应从 Admin 管理后台进入文档页，由 Admin 完成登录安全链、`docs.api_service.index` 入口权限和 `site=api + path` 正文权限校验后，再通过 `api_service.internal_base_url` 内网读取。
