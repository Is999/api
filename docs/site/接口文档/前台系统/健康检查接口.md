# 健康检查接口

## 存活检查

`GET /api/live`

该接口为公开路由，不校验 token，不访问外部依赖，供 livenessProbe 使用。

### 安全字段

| 项目 | 字段 |
|------|------|
| 请求签名字段 | 不参与签名 |
| 请求加密字段 | 不参与加密 |
| 响应签名字段 | 不参与签名 |
| 响应加密字段 | 不参与加密 |

### 响应示例

```json
{
  "status": true,
  "code": 200,
  "message": "请求成功",
  "data": {
    "status": "ok",
    "mode": "api",
    "node": "api-1",
    "version": "5d41402a"
  }
}
```

## 就绪检查

`GET /api/ready`

该接口为公开路由，不校验 token，会探测 MySQL 和 Redis，供 readinessProbe 和发布流量切换使用。

`data.dependencies` 由组件生命周期注册表生成；配置命名扩展库时追加对应 MySQL 项，已启用的 Collector 等组件也参与检查。独立组件并行探测，每项检查上下文最长 2 秒，结果按注册顺序返回；无检查函数的组件直接返回 `ok`。`data.version` 是配置指纹，不是二进制构建版本。

### 安全字段

| 项目 | 字段 |
|------|------|
| 请求签名字段 | 不参与签名 |
| 请求加密字段 | 不参与加密 |
| 响应签名字段 | 不参与签名 |
| 响应加密字段 | 不参与加密 |

### 响应示例

```json
{
  "status": true,
  "code": 200,
  "message": "请求成功",
  "data": {
    "status": "ok",
    "mode": "api",
    "node": "api-1",
    "version": "5d41402a",
    "dependencies": [
      {
        "name": "mysql",
        "status": "ok"
      },
      {
        "name": "redis",
        "status": "ok"
      }
    ]
  }
}
```

### 异常说明

依赖不可用时 HTTP 状态码返回 `503`，业务码返回 `50001`，`data.dependencies` 会带具体依赖、业务码和稳定文案“依赖不可用”。数据库地址、驱动错误和其它内部详情只进入服务端日志与 trace，不通过公开 readiness 响应返回。

## 指标抓取

`GET /api/metrics`

该接口不校验 token，但只注册到独立内网监听器，供 Prometheus 直接抓取运行指标；公网监听器访问同一路径返回 `404`。生产内网监听器必须绑定私网地址，并通过安全组、NetworkPolicy 或 mTLS 限制 Prometheus 来源。

### 安全字段

| 项目 | 字段 |
|------|------|
| 请求签名字段 | 不参与签名 |
| 请求加密字段 | 不参与加密 |
| 响应签名字段 | 不参与签名 |
| 响应加密字段 | 不参与加密 |
